# Glass Launcher
1. Open this folder in Android Studio (Koala or newer); let Gradle sync.
2. Run on your phone (USB debugging) or an emulator.
3. Press Home -> choose "Glass Launcher" -> Always.
Effects: Android 13+ = blur + AGSL refraction, 12 = blur only, 8-11 = translucent fallback.
Tweak glass in Glass.kt (refraction, blur radius, depth 28.0). Swap Wallpaper() for your own bitmap.
